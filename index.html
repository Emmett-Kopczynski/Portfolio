Project 1 :  GTK Calculator

Description:

A graphical calculator application for linux made in C using the GTK graphics library.
The calculator support basic operations like addition, subtraction, division, and multiplication.
The calculator does math using order of operations, it does order of operations by converting an
infix equation into a postfix equation and then evaluating the postix expression.

Github Link : https://github.com/Emmett-Kopczynski/GTK-CALC
