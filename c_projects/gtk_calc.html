GTK Calculator

Github Link : https://github.com/Emmett-Kopczynski/GTK-CALC

This Project is a graphical calculator made in c that uses the GTK4 library (https://www.gtk.org/) for the graphical interface. The calculator follows order of operations, and does so by converting the given infix operation (ex: 1 + 4 / 2) and converts it to the corresponding postfix operation (ex: 4,2,/,1,+) with an algorithm that relies heavily on the stack data structure before calculating a final answer.

The Calculator can handle the vast majority of errors gracefully, printing error messages like "CANNOT DIVIDE BY ZERO" when a user tries to divide by zero and "PARENTHESIS ERROR" when the syntax surrounding parenthesis is disobeyed.
